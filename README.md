# Machine_Learning-Part1 : EDA & Feature Engineering
This project focuses on the fundamentals of Machine Learning, with an emphasis on Exploratory Data Analysis (EDA) and Feature Engineering, which are critical steps before building any predictive model.

🔍 Exploratory Data Analysis (EDA)

In this project, I explored the dataset to understand its structure, patterns, and relationships between variables. The EDA process was carried out step by step with a clear analytical mindset, including:

Understanding the dataset and its features

Identifying missing values and data types

Analyzing distributions and trends

Studying relationships between variables

This process helped in making informed decisions before moving to modeling.

🛠 Feature Engineering & Feature Extraction

To prepare the data for modeling, several feature engineering techniques were applied:

Converted binary outcome variables into numerical form (0 and 1)

Performed feature extraction by transforming categorical features such as region into multiple columns using encoding techniques

Ensured the dataset was model-ready and suitable for regression analysis

📊 Correlation Analysis

Implemented Pearson correlation to:

Measure the linear relationship between numerical features

Identify strongly correlated variables

Support feature selection and reduce redundancy

📈 Model Implementation

Finally, a Linear Regression model was implemented to:

Train the model on the processed dataset

Evaluate model performance

Check the efficiency and predictive capability of the model

🚀 Key Learnings

Structured approach to EDA

Practical feature engineering techniques

Understanding and applying Pearson correlation

Hands-on experience with Linear Regression

This project serves as a strong foundation for more advanced Machine Learning concepts and models.
